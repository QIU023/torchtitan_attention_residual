## 一、结论

**4/4 步全环**:vLLM rollout → TransferQueue → titan log-prob → GRPO adv →
update_actor → 权重同步 → 下一轮 rollout。质量信号:

- `rollout_actor_probs_pearson_corr = 0.9999`,probs_diff_max ~1e-5,
  KL ~5e-5 —— 生成侧与训练引擎逐 token 对得上,权重同步正确(与 Stage 0
  同一判据)。
- 45 s/步、~364 tok/s、actor 峰值 11.4 GiB。
- reward/advantage/pg_loss 全 0:随机权重 debug 模型在 GSM8K 拿不到分
  (响应 99% 顶到 256 上限)——**环路机械闭合、模型太弱无信号**,与
  447M 全管线时代同款结论;infra 判定不受影响。
