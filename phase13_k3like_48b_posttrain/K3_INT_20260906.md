  `rl` carries exactly that shape (`local_hacks/rl_flavor_newtree.patch`); `hf_export_shape_check`
  OK, and venv_verl's vLLM loads and decodes it (`vllm_moe_rollout_probe.py` on the new dir).
- The rebase's whole-file conflict resolutions had dropped upstream content in two files; repaired in
  `2813dd18`: `vllm_async_server.py` is upstream's file plus the `VERL_VLLM_VERSION` override (the
  rebased verl gates on vLLM >= 0.18.0, so the source build claims 0.18.0 now), and the engine carries
  upstream's sharded delta export helpers (#7324) next to our LoRA-aware sync and CP / PP.
- The engine's no-op dataloader config gained a `dataset` field: the new tree's K3 model config reads
