# H200 box (217.18.55.111): the environment that ran MoonEP and the K3 trees, step by step (2026-09-17)

Box: 4 x H200 143 GB, NV18 every pair, NVSwitch (Fabric State Completed), multicast on all four; Ubuntu 22.04 container with miniconda only, nvcc 12.6 at `/usr/local/cuda-12.6`, driver 595.58.03. Scripts and logs of the setup: `Raising_PRs/PR_K3_PARALLELISM/logs_moonep_2026-09-17_h200/setup/` (`setup_env.sh`, `setup_stage2.sh`, `setup_uv.sh`, their logs) and `kit_h200/` (`env.sh`, every runner, the probes, the patches).

1. Python: `conda create` produced no env silently; `uv venv --python 3.12 /workspace/venv_k3` (uv from the miniconda py3.10 env) worked. Everything below with `VIRTUAL_ENV=/workspace/venv_k3 PATH=/workspace/venv_k3/bin:$PATH` and `uv pip install`.
2. torch: `torch==2.15.0.dev20260906+cu126` and `torchvision==0.30.0.dev20260906+cu126` from `https://download.pytorch.org/whl/nightly/cu126`; the two must carry the same date (the 0907 torch has no torchvision partner and pip fails). cu126 matches the box's nvcc, so MoonEP builds without a CUDA 13 toolkit; Hopper needs nothing newer.
3. The tree's requirements (`.ci/docker/requirements.txt` of main `a3a819c67`): `grain==0.2.18 datasets>=3.6.0,<4.8.0 tensorboard wandb tyro tokenizers safetensors einops pillow spmd_types==0.2.5 av torch_remat@git+...d302699 renderers==0.1.11 ninja pytest expecttest` (`renderers` is new on main; `expecttest` is needed by `DTensorTestBase` tests).
4. Attention Gym: the same checkout the 5060 box uses (`b19162e`, upstream `meta-pytorch/attention-gym`; the fork clone lacks it) shipped as a tarball without `.git`, installed with `SETUPTOOLS_SCM_PRETEND_VERSION=0.0.8 uv pip install --no-deps -e /workspace/attn_gym_src` (hatch-vcs needs a version), plus `apache-tvm-ffi>=0.1.12`.
5. cutlass-dsl: `nvidia-cutlass-dsl==4.6.0` with `nvidia-cutlass-dsl-libs-cu12` (Attention Gym's KDA CuTe backend needs >= 4.5; PyPI has no 4.5.x). MoonEP pins 4.4.2; on 4.6.0 its grad-reduce kernel needs the one-line rename `cute.make_fragment` to `cute.make_rmem_tensor` (`kit_h200/moonep_grad_reduce_cutlass46.patch`), after which all six MoonEP suites pass.
6. MoonEP `2bd860b`: `CUDA_HOME=/usr/local/cuda-12.6 TORCH_CUDA_ARCH_LIST=9.0 MAX_JOBS=48 pip install --no-build-isolation --no-deps -e .` (about 3 minutes), then the patch of step 5.
7. Trees: `/workspace/tt_main` (upstream `a3a819c67`), `/workspace/tt_ac` (`k3_ac_reuse_attention`), `/workspace/tt_moonep` (`k3_moonep_seam`); every K3 tree on Hopper takes `matrix_scripts/local_hacks/kda_sm120_guard_lift.patch` (the model refuses non-Blackwell GPUs otherwise), plus the local flavor patches (`moonep_onbox/0002...`, `0003...`, `ac_h200/0004...`, `0005...`).
8. Runs: `source /workspace/kit/h200/env.sh` first (`NCCL_NVLS_ENABLE=0`, `MOONEP_MEM_HANDLE_TYPE=auto`, caches). Two pitfalls: a `pkill -f <pattern>` must sit in its own ssh call (the remote shell's cmdline contains the later text and matches itself); the matrix runner's `ALL_DONE` marker must be read after the last `RESTART` line or a queued driver starts early.
