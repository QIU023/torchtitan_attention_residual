## CP composed with PP or TP: refused on this tree

`parallelize_kimi_k3` on the tree (from PR 4639's K3 commit) raises `NotImplementedError("Kimi K3 does not support context parallel with tensor parallel, context parallel with pipeline parallel")` (`parallelize.py:75`); the cp2 x tp2 and cp2 x pp2 cells (`int0915_logs/run_int0916_cpcross.sh`, tower cut, seeded) stop there, and cp2 x pp2 additionally needs the b200 recipe's SPMD type checking off (type checking refuses a pipeline). So on this tree CP composes only with FSDP and EP. The RFC's 3-of-4 matrix cells with CP (fsdp x tp x cp, fsdp x pp x cp, tp x pp x cp) therefore cannot run until that refusal is lifted and the two combinations made to work on 4639's CP; the old tree ran tp x cp with sequence parallel off (`K3 mm18`) and pp x cp (the 09-10 hang note) on our own CP, whose block-stack and head-split cp adaptations this tree still carries (`7ac90adbf`, `16d97ac53`). A maintainers' decision as much as ours: 4639 is theirs.
