# SFT and GRPO dataset selection (chosen, NOT downloaded)

Recorded so the choice is fixed and reviewable before any bytes move. Nothing
here is fetched: this box is a single RTX 5060 Ti (16 GB, and fla's KDA kernel
already does not fit its shared-memory limit at some configs), so real training
is not possible locally. What runs here is smoke -- shape, wiring, gradient and
loss-curve checks -- against dummy data generated by
`scripts/make_dummy_datasets.py`.

## SFT

| role | dataset | why |
|---|---|---|
| multimodal | `liuhaotian/LLaVA-Instruct-150K` | Used in this project's earlier VLM phases, so the collator and image_mask path already have precedent against it. Single-image conversations match the interleaving `model.py` implements. |
| text-only | `teknium/OpenHermes-2.5` | No licence gate, plain conversational JSON, no bespoke parsing. Keeps the text-only SFT leg independent of the vision stack so a failure localizes. |

## GRPO

| role | dataset | why |
|---|---|---|
| text reasoning | `openai/gsm8k` (main split) | The reward must be programmable. GSM8K has a single numeric ground truth, so exact match after `####` extraction is the whole reward function -- no reward model, no judge. That is the only kind of RL loop this hardware can host. |
| multimodal | `HuggingFaceM4/VQAv2` | Same property for images: short answers with exact-match scoring against ten human annotations, so the standard VQA accuracy metric doubles as the reward. Also the series we used before. |

Deliberately NOT chosen, with reasons:

- Preference sets (HH-RLHF, UltraFeedback): need a reward model, which needs its
  own training run. No.
- MATH / AIME: answers need symbolic equivalence checking, so the reward function
  becomes its own correctness problem on top of the RL loop.
- Obelics (interleaved multimodal pretraining): the multimodal *training* blocker
  named in earlier docs. It is a pretraining corpus, not an SFT or RL set, and it
  is large. Out of scope for both legs here.

## What runs locally

`make_dummy_datasets.py` emits the four shapes above with the same field names
and the same collator contract, at a size that fits this GPU. Its purpose is to
exercise wiring, not to learn anything: a smoke that passes on dummy data proves
the plumbing, and proves nothing about quality. Any curve produced from it must
be labelled as such.
