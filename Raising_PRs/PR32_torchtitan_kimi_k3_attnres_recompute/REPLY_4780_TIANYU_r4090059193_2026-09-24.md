The zero init is its own PR now, #INIT_PR: one commit on main with its test. This PR no longer touches `__init__.py`.

The autograd Function is gone. Each aggregation runs under `remat.checkpoint` when autograd records it and no AC policy wraps its block, so backward rebuilds the FP32 copies instead of keeping them. Under selective, full and region AC, `KimiK3Model.parallelize` marks the blocks, and the aggregation runs as a plain call inside the block's checkpoint. Region AC needs that, because torch_remat rejects a nested checkpoint. This is the change #4656 proposed before #4810, so #4656 can be closed in favour of this PR.

`_apply_attention_residual` is now `AttentionResidual`, a `Function` whose default is the reference implementation, with one config node per residual site. The weights keep their names. The checkpoint sits at the call site, so it wraps whichever implementation the node builds. The override is left to @acisseJZhong, as suggested.
