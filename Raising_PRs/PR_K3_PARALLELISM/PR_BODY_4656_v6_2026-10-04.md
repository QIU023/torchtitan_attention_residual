## Summary

Carry Kimi K3's attention-residual blocks inside the model as a list of [T, D] tensors instead of a [T, N, D] stack, so a block opening appends a reference instead of building a longer copy, and the activation checkpoints of later layers share the same blocks.

- `kimi_k3/model.py`: the blocks are a list; `_apply_attention_residual` stacks it inside the call, so the arithmetic is unchanged. The model's forward still takes and returns the stack, so the pipeline stage is unchanged.
- `kimi_k3/sharding.py`: the layer 0 boundary of the multimodal decoder converts no stack, since the list starts empty.

## Design

Every block opening used to concatenate a longer stack, and each layer's checkpoint kept the stack it was called with, so under full, selective or region activation checkpointing every shorter copy stayed alive until backward: for 24 layers in blocks of 4 the checkpoints held 21 [T, D] units where the blocks are 6. A checkpoint keeps its inputs by reference, so with a list every checkpoint references the same six blocks.
