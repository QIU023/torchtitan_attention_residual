# Compile PR runs, 2026-09-14 (one RTX 5060 Ti, venv_bfx9, attn_gym main, KDA guard lifted locally)

- `h_*`: final branch state (decoder and tower compiled), one shared warm cache `cache_w`; `h_eager_fresh1/2` on fresh caches (noise floor). `g_*.txt`: step-1 gradient per parameter against the `h_eager` reference (bitwise flag, max abs, relative norm difference); `g_eager.txt` holds the reference norms.
- `f_*`: the revision without tower compile (decoder only), shared cache `cache_final`; `f_compiled2` is the rerun on the same cache.
- `eager.log` / `compiled.log`: the revision with `KDAKernel.forward` under `torch.compiler.disable` and `fullgraph=False` (bitwise with eager over three steps).
- `probe_*`: decoder compiled through the KDA wrapper with `fullgraph=True` (probe tree): cold cache, warm cache, and `aot_eager`.
- Autotune benchmark lines are stripped from the logs; `run*.sh` are the runners.
- `t_*`, `t6_*`, `tap6_compare.txt`: layer-23 gradient taps (`probe_tap.py`, an identity custom op whose backward records the gradient at runtime; no graph break under `fullgraph=True`), eager against `aot_eager`, first two micro-batches of step 1; `probe6_model_taps.diff` and `probe_trainer_hack.diff` are the scratch edits. `t_aot_eager.log` is the first attempt, stopped by the recompile limit (the tap flag adds a guard variant); `t_aot_eager2` reran it with the limit raised in the probe only.
- `h_compiled2.log`: second reading of the final inductor cell. `h_compiled10.log`: the branch state compiled for ten steps with `TORCH_LOGS=recompiles` (8 compiled variants of `checkpoint_wrapper.forward`, the default limit). `h_compiled33.log`: the branch state on a 33-layer model (scratch copy, `_debugmodel` `num_layers=24` changed to 33; main has no 33-layer flavor): stops before step 1 with `Dynamo recompile limit exceeded` (9 variants of `checkpoint_wrapper.forward` needed). `h_compiled33_limit32.log`: the same with the limit raised to 32 in the scratch copy.
- `r_*`: the branch with `raise_dynamo_recompile_limit` (core helper; Kimi K3 bound from the model config): `r_compiled24` and `r_eager24` on the shared cache read the earlier rows exactly; `r_compiled33` (33-layer scratch copy) trains with 9 wrapper variants, where the branch without the helper stopped at the default limit of 8.
