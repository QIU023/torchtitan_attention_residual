## Summary

Kimi K3's attention residual keeps each block once: the blocks travel as a list of [T, D] tensors that every layer shares, instead of a [T, N, D] stack that each block opening copies.

- `kimi_k3/model.py`: a block opening appends to the list; it used to concatenate a longer stack. `_apply_attention_residual` stacks the list inside the call, so its arithmetic is unchanged.
- `kimi_k3/sharding.py`: layer 0's multimodal boundary converts no stack, since the list starts empty and its first block is layer 0's converted input.
- `kimi_k3/pipeline_parallel/stage.py`: the stage hands the model its assembled stack as views and takes its commits and payload from the returned list; core still reads the input gradients off the stack leaf.

## Design

With the stack, each block opening makes a longer copy, and every earlier layer's checkpoint keeps the stack it was called with, so all the copies live until backward. Counted on CPU at [T, D] = [64, 32], a 24 layer model in blocks of 4 keeps 21 [T, D] units alive where the blocks are 6, under full, selective and region AC alike, since each block checkpoint takes the stack as an input. With the list every checkpoint references the same six blocks.
