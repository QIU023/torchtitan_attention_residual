# grad norm fp32：pytorch 合入后 titan 还要改什么（2026-10-08）

- **pytorch PR 194033 已合入：** 10-07 17:06 UTC，main `294bc517d9a7`，janeyx99："it will be in the 2.16 release"。
  - `torch.nn.utils.get_total_norm` 多了 `dtype: torch.dtype | None = None`，`None` 时行为不变；
  - 同一个 PR 修了 DTensor 的 `_foreach_norm.Scalar` 策略，所以 FSDP 和 TP 的 DTensor 梯度传 `dtype=` 不会再报错。
  - 2026-10-08 的 nightly（源 `79ef85d9b6`）已包含它（compare：领先 47 个提交，落后 0 个）。
- **titan #4135 已关：** tianyu-l 10-07 06:01 UTC 关的，没有留言，比 pytorch 合入早 11 小时。08-18 在 #4135 上答应过："once that part is merged I will update this titan PR ... with the duplicate helper function deleted"。
- **titan main（`08f7c391b`）还没用上：** `torchtitan/distributed/utils.py` 里三处 `torch.nn.utils.get_total_norm(grads, norm_type, error_if_nonfinite, foreach)`（第 549、608、615 行，普通路径一处，EP 路径两处）都没传 `dtype`，所以 bf16 梯度仍然按 bf16 累加。全仓只有这个函数算 grad norm（`components/optim/optim.py` 和 torchft 都调它）。
- **titan 要做的改动：** 三处加 `dtype=torch.float32`。
  - 返回的 total norm 变成 fp32，后面的 `full_tensor()`、EP 两组合并、PP 的 all-reduce 和 clip 系数自然都在 fp32 里做；
  - #4135 里的 `_get_total_norm_fp32` helper 不再需要；
  - titan CI 每个 job 都装最新的 nightly（cu130 / cu132，不钉版本），所以现在开 PR 就能跑到。
- **影响范围：** 只在梯度是 bf16 或 fp16 时（`training.dtype="bfloat16"`）。默认 float32 时，#4135 当时测的是改前改后逐字节相同；新写法要重新确认一次。
- **我们的分支：** `k3_on_4025`、`k3_pp_mm`、`k3_cp_mm`、`moonep_review1`、`k3_cp_muon_layout` 都没带旧 helper，不用清理。
