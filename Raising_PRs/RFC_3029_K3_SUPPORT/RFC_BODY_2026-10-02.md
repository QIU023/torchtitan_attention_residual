## Summary

Track end-to-end Kimi K3 support in torchtitan: the model and its parallelisms on main, the training-side infrastructure the Kimi K3 technical report describes (cache-based pipeline communication for Attention Residuals, recompute of the AttnRes math, dynamic context parallelism and the decoupled encoder process for the vision tower, balanced expert parallelism, MXFP4 / MXFP8 quantization-aware training), and post-training (SFT, LoRA / QLoRA, GRPO) on the same model code.

Scope and ownership:

- #4272 is the tracking list for the production path and holds the P0 / P0.5 / P1 checkboxes; this RFC does not duplicate them.
- This RFC records status per component with links, and carries the deliverables for the scope #4272 does not list.
- Every row names its PR; the PR carries its own review thread.

## The released model (per the model card and `torchtitan/models/kimi_k3/README.md`)

2.8T total, 104B activated; 93 decoder layers (1 dense), hidden size 7168, 96 attention heads; 69 KDA layers and 24 Gated MLA layers; Attention Residuals in blocks of 12 layers; Stable LatentMoE with latent dimension 3584, 896 experts, top-16, 2 shared experts, SiTU-GLU; 160K vocabulary; MoonViT-V2 vision encoder (401M); 1M-token context; MXFP4 weights and MXFP8 activations with quantization-aware training. The debug flavour keeps the layer pattern at 17 layers, in attention-residual blocks of 4.

## Building blocks on main

- Model code and its seams are on main: `models/kimi_k3/` (model, `flavors.py`, `kda.py`, `moe.py`, `sharding.py`, `state_dict_adapter.py`, `vision_encoder.py`, and `pipeline_parallel/` for the AttnRes stage), core's `RoutedExperts`, `TokenChoiceTopKRouter`, `TokenDispatcherTransform`, `pipeline_llm`, `RegionAC` / `torch_remat`, local compile, the LoRA and quantization config transforms.
- Sibling models set the pattern each K3 piece follows: Kimi K2.5 for the MoonViT tower (its TP plan is now shared), Qwen3.5 for the hybrid linear-attention decoder, DeepSeek V3 for MLA and MoE.
- Every new piece extends one of these; a private helper, hook or side structure is a review finding, not a design.
